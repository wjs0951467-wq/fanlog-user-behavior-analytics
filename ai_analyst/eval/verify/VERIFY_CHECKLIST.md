# 후보 질문 검증 체크리스트

이 표는 사람이 채운다. `reference_queries.sql` 의 SQL 을 DBeaver(읽기 전용 계정 fanlog_ro)에서 한 문항씩 실행하고,
결과를 "내가 적을 결과" 칸에 적은 뒤, SQL 이 질문의 정답이 맞다고 판단하면 `[x]` 로 바꾼다.

규칙
- 이 초안은 정답이 아니다. Claude Code 는 SQL 을 실행하지 않았고 결과 값을 모른다.
- 모델이 낸 SQL 이나 숫자와 비교해서 정답을 정하지 않는다. 정의는 `semantic_layer.yaml`, PRD, 데이터 사전을 근거로 사람이 판단한다.
- 결과가 0행이거나 0이면 그 문항은 구분력이 약하다(아무 SQL 이나 0을 내면 맞는다). 질문을 바꾸거나 뺀다.
- 확인이 끝난 문항만 `questions.yaml` 로 옮기고 `verified: true` 로 바꾼다. 보류(heldout)로 쓸 문항은 그 뒤로 모델에 물어보지 않는다.
- 결과 칸에는 집계 값만 적는다. 사용자 ID 같은 개별 값은 적지 않는다.
