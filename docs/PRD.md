# FANLOG 사용자 행동 분석 대시보드 PRD

## 1. 프로젝트 개요

본 프로젝트는 가상의 아이돌 팬덤 플랫폼 `FANLOG`에서 발생하는 사용자 행동 데이터를 설계·생성하고, 이를 분석하여 주요 서비스 지표와 분석 결과를 시각적으로 확인할 수 있는 운영 대시보드를 구현하는 프로젝트이다.

회원가입, 아티스트 팔로우, 콘텐츠 조회, 좋아요·댓글, 상품 조회, 장바구니 추가 및 구매로 이어지는 사용자 여정을 기준으로 가상 행동 데이터를 구성한다. 이를 활용하여 사용자 활동 현황, 서비스 이용 퍼널, 재방문, 콘텐츠 참여도, 상품 구매 전환율 및 사용자 유형별 행동 차이를 분석한다.

분석을 통해 사용자가 서비스 이용 과정에서 이탈하는 주요 지점과 콘텐츠 참여 및 상품 구매에 영향을 주는 행동 특성을 파악한다. 최종적으로 팬덤 플랫폼 운영자와 서비스 기획자가 주요 지표를 확인하고 의사결정에 활용할 수 있는 대시보드를 제공하며, 팬 활동과 구매 전환을 높이기 위한 데이터 기반 서비스 개선 방안을 제안한다.

본 프로젝트에서 사용하는 데이터는 실제 사용자 정보가 아닌 분석 목적의 가상 데이터이며, 실제 팬덤 플랫폼에서 발생할 수 있는 사용자 행동과 운영 상황을 가정하여 구성한다.
